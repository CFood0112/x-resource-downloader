# X 喜欢视频批量下载

这套工具会自动打开你登录态的 Chrome，滚动你的 X 喜欢列表，挑出带视频的推文，再用 `yt-dlp` 批量下载。已下载过的视频会通过 `archive.txt` 自动跳过，下次运行只下载新增的。

推荐直接双击 `x_video_downloader.bat`，会打开本地图形界面，显示当前状态、网速、剩余时间、进度条、当前第几个视频、运行日志和失败列表。运行日志会保存在 `logs\` 目录，失败下载会额外写入 `logs\failures_*.txt` 和 `logs\errors.log`。

不想用图形界面时，也可以双击 `menu.bat` 使用命令行菜单：

```text
1. 采集最近 50 条喜欢视频并下载
2. 采集最近 100 条喜欢视频并下载
3. 自定义采集数量
4. 只下载新增（用上次采集的列表）
5. 手动粘贴链接下载
0. 退出
```

每次采集都会跳过 `seen_urls.txt` 里已经采集过的视频，继续向下滚动寻找新的 N 条；下载时再通过 `archive.txt` 跳过已经下载过的视频。所以重复运行“最近 50 条”会逐步推进到更早的喜欢视频，不会每次都拿到同一批。下载优先使用 X 直链的最高码率 MP4，一条推文里有多个视频时也会全部下载，文件名会带 `- 1`、`- 2` 等编号。

图形界面的进度条、百分比、网速、剩余时间会实时更新；运行日志只保留关键事件，不再刷屏显示每一条进度信息。

## 第一次使用

1. 确认本机已安装 Chrome（会自动使用系统 Chrome）。
2. 运行：

```powershell
.\run_all.ps1
```

3. 如果弹出的 Chrome 没有登录，先在窗口里登录 X。登录后脚本会自动识别你的用户名，并开始滚动喜欢列表。
4. 完成后视频默认全部保存在 `videos\` 下。

也可以直接运行 `.\run_all.ps1`，效果等同于菜单里的“采集 100 条并下载”。

## 图形界面设置

图形界面右上角设置区可以调整：

- 文件夹结构：全部放在 `videos` / 按发布者 / 按月份 / 发布者 + 月份
- 命名格式：`日期-发布者-ID`，或追加最多 40 个字符的短标题
- 代理：自动 / 关闭 / 自定义地址
- 手动下载时是否强制重新下载

命名格式默认使用纯 ASCII 安全字符（日期、发布者用户名、视频 ID），避免 emoji、中文等字符在文件系统里出现编码问题。

## 手动下载指定链接

在菜单选 5，或运行：

```powershell
.\manual_download.ps1
```

脚本会优先读取剪贴板里的链接；也可以手动粘贴，每行一个，最后输入空行结束。下载时会询问是否跳过已下载过的视频。

## 单独运行

只想采集链接：

```powershell
.\collect_likes.ps1
```

只想下载已有链接：

```powershell
.\download_videos.ps1
```

## 自动定时

每周日 03:00 自动执行一次：

```powershell
.\install_scheduler.ps1
```

改成每天执行：

```powershell
.\install_scheduler.ps1 -Frequency daily
```

删除计划任务：

```powershell
Unregister-ScheduledTask -TaskName 'X Liked Videos Download' -Confirm:$false
```

## 参数

`config.json` 里的常用项：

- `username`：X 用户名，第一次运行后会自动写入
- `maxLikesToScan`：最多收集多少个视频链接
- `maxScrollAttempts`：最多滚动多少轮
- `downloadDir`：视频保存目录（默认 `videos`）

## 注意

- 工具只用于下载自己的喜欢列表，请仅作个人使用。
- 自动访问 X 有账号风控风险，建议控制频率，不要频繁刷列表或下载超大数量。
- `cookies.txt` 包含你的登录凭证，不要外传，也不要提交到 git。
